# Personal portfolio

A responsive, static five-page portfolio built with HTML, CSS, and JavaScript. Open `index.html` in a browser; no installation or build is required.

## Pages

- Home: introduction and navigation
- About: background, education, and interests
- Projects: three illustrated example project concepts
- Skills: editable skills and proficiency levels
- Contact: JavaScript validation and an email draft via `mailto:`

## Personalize before submitting

Replace Adria if needed. Fill in bracketed background and education details in `script.js`, replace the example skills with accurate proficiencies, and replace all three example projects with your own descriptions and screenshots. Add repository or live links where available. Replace every `hello@example.com` in `script.js` with your email.

The project illustrations are local SVG mockups, not screenshots of completed work. The contact form does not send messages: it opens an email draft for visitors to review and send through their email app. Google Fonts are optional; system font fallbacks work offline.

## Interactive models

Projects now includes a self-hosted Three.js STL viewer with orbit/pan, zoom, reset, keyboard-operable controls, and wireframe mode. Serve the site over HTTP(S) for this feature. 4X Lesson 4 now has a real interactive mesh converted from its OBJ export. Titan 8M and Titan 9M still need mesh exports; see `assets/models/README.md`. Viewer dependencies are local and include their license.
